# A-Level Notes

这个仓库用于整理和分享我在 A-Level 学习过程中积累的笔记、知识点总结、题型归纳和复习资料。

内容以个人学习理解为主，适合用于课后复习、考前梳理和查漏补缺。仓库会随着学习进度持续更新。

## 内容说明

这里的笔记主要包括：

- 章节知识点总结
- 高频考点整理
- 典型题型与解题思路
- 易错点记录
- 考前复习提纲
- 个人补充材料

## 使用方式

你可以直接浏览仓库中的 Markdown、PDF 或其他笔记文件，也可以将仓库克隆到本地



如果只是复习某个主题，建议按以下顺序使用：

1. 先阅读对应章节的知识点总结。
2. 再查看题型归纳和易错点。
3. 最后结合 past paper 或练习题进行巩固。
