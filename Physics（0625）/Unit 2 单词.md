| English Term         | 中文对应      | 备注/说明 (中/En)                                                                       |
| -------------------- | --------- | ---------------------------------------------------------------------------------- |
| Motion               | 运动        | 描述物体的运动状态 / description of an object’s movement                                    |
| Distance             | 距离        | 标量，只考虑大小 / scalar, only size matters                                               |
| Displacement         | 位移        | 矢量，起点到终点的直线距离和方向 / vector, straight line distance from start to end with direction |
| Speed                | 速率        | 标量，只有大小 / scalar, magnitude only                                                   |
| Velocity             | 速度        | 矢量，大小+方向 / vector, magnitude + direction                                           |
| Oscillate / Vibrate  | 震动 / 振动   | 往复运动 / repetitive back-and-forth motion                                            |
| Rotate               | 转动        | 绕轴旋转 / turning around an axis                                                      |
| Translational        | 平动        | 整体沿直线或曲线平移 / whole body moves without rotation                                     |
| Instantaneous        | 瞬时速度      | 在某一瞬间的速度 / velocity at a particular instant                                        |
| Average speed        | 平均速度      | 总路程 ÷ 总时间 / total distance ÷ total time                                            |
| Gradient / Slope     | 斜率        | 图像中表示速度或加速度 / slope in graph shows speed or acceleration                           |
| Uniform              | 匀速 / 均匀   | 速度大小不变 / constant speed                                                            |
| Scalar               | 标量        | 只有大小，无方向 / magnitude only, no direction                                            |
| Vector               | 矢量        | 有大小和方向 / has both magnitude and direction                                          |
| Magnitude / Size     | 大小        | 数值部分 / numerical value of a quantity                                               |
| Direction            | 方向        | 矢量的方向性 / orientation of a vector                                                   |
| Linear / Rectilinear | 直线 / 线性运动 | 沿直线运动 / motion in a straight line                                                  |
| danCircular          | 圆周运动      | 沿圆轨迹运动 / motion along a circular path                                              |
